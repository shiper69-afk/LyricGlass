## LyricGlass v0.8.2

### Highlights

- **Particles visualizer fixed**: continuous motion from audio level and frequency bands; beat bursts using the Rust beat flag plus a JavaScript energy fallback when beats are sparse.
- **Five new styles**: Warp (starfield), Mirror, Tunnel, Matrix, Terrain—full-viewport canvas with vivid cyan, magenta, violet, and orange glow matching existing modes.

### Which file to download?

| Asset | When to use |
| --- | --- |
| **LyricGlass_0.8.2_portable.exe** | Run anywhere; no install (same as CI `lyricglass.exe`). |
| **LyricGlass_0.8.2_x64-setup.exe** | NSIS installer to `%LOCALAPPDATA%\LyricGlass` with uninstaller. |

**Windows x64** and **WebView2 Runtime** are required. See [README.md](../README.md) for setup details.
